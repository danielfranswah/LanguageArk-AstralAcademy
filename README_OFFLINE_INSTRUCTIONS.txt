HOW TO RUN THE APPLICATION:
-------------------------------------------------------------------
METHOD 1 (Universal - All Operating Systems):
1. Simply double-click "index.html" in this folder.
2. It will open immediately in your web browser (Chrome, Safari, Firefox, Edge, etc.).

METHOD 2 (macOS Launcher):
1. Double-click "Launch_Language_Ark.command" to open index.html automatically.

METHOD 3 (Windows Launcher):
1. Double-click "Launch_Language_Ark.bat".
